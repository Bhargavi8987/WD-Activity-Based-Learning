Consolidated HTML and CSS Website Projects 1. Introduction This repository contains three beginner-friendly website projects developed using HTML and CSS. The projects demonstrate webpage structure, navigation, content organization, styling, and layout design. Each project includes HTML source code, CSS styling code, and an output preview. 2. Technologies Used HTML5:** Used to create the structure and content of webpages. CSS3:** Used to style webpages with colors, backgrounds, spacing, typography, and layouts. Visual Studio Code:** Used to write and edit the source code. Web Browser:** Used to view and test the website outputs. 3. Projects Overview Project 1: Restaurant / Cafe Website Description: A simple cafe website that displays menu items, prices, basic information, and contact details. Main Features: Cafe heading and tagline Navigation links Menu cards for pizza, burgers, and coffee About and contact sections Styled layout with colors and spacing Files: `index.html` and `style.css` Project 2: Online News Portal Description: A basic news portal that groups sample news content into clear categories. Main Features: Daily News heading Navigation links for news categories Latest headlines National, sports, and technology sections Structured news content and footer Files: `index.html` and `style.css` Project 3: Movie and Rating Website Description: A movie-listing website that presents movie names, genres, and audience ratings. Main Features:** Movie World heading Navigation links Movie cards with genres Ratings for sample movies Styled content sections and footer Files: `index.html` and `style.css` 4. Project Folder Structure Each project contains its HTML and CSS files in the same folder. ```text Website-Projects/ ├── README.md ├── Project-1-Restaurant-Cafe/ │ ├── index.html │ └── style.css ├── Project-2-Online-News-Portal/ │ ├── index.html │ └── style.css └── Project-3-Movie-Rating/ ├── index.html └── style.css ``` 5. How to Run the Projects 1. Download or clone the repository from GitHub. 2. Open the required project folder. 3. Open `index.html` in a web browser. 4. Check the page heading, navigation links, content sections, and footer. 5. Edit `style.css` to change the design, colors, spacing, and layout. 6. Testing and Results Each project can be tested by opening its HTML file in a web browser. Verify that the page content appears correctly and that the CSS styles are applied. If the design does not appear correctly, check that the HTML file links to the correct CSS filename and that both files are saved in the expected folder. 7. Conclusion These three projects provide practical experience in creating structured webpages and styling them with CSS. The restaurant website demonstrates menu cards and contact information, the news portal demonstrates category-based content, and the movie website demonstrates movie cards with genres and ratings.
